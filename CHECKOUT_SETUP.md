# Инструкции по настройке системы оплаты и доставки

## 📋 Обзор

Система оформления заказов включает:
- ✅ Выбор способа оплаты (карта / наложенный платеж)
- ✅ Выбор метода доставки (Econt офис/автомат / на адрес)
- ✅ Интеграция с Econt API для получения списка офисов и городов
- ✅ Уведомления в Telegram с полной информацией о заказе
- ✅ Очистка корзины после успешного заказа

## 🔧 Настройка переменных окружения

### 1. Скопируйте `.env.example` в `.env.local`

```bash
cp .env.example .env.local
```

### 2. Заполните переменные для Econt API

#### Для разработки (demo-система):
```env
ECONT_API_URL=https://demo.econt.com/ee/services
ECONT_USERNAME=iasp-dev
ECONT_PASSWORD=1Asp-dev
```

#### Для production:
1. Зарегистрируйтесь на https://www.econt.com/services/api.html
2. Или используйте существующие учетные данные e-econt
3. Обновите переменные:

```env
ECONT_API_URL=https://ee.econt.com/services
ECONT_USERNAME=ваш_username
ECONT_PASSWORD=ваш_пароль
```

### 3. Убедитесь, что Telegram настроен

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
```

Как получить:
- **Bot Token**: Создайте бота через @BotFather в Telegram
- **Chat ID**: Используйте @userinfobot или @getidsbot

## 📦 Что было реализовано

### 1. Типы данных
- `types/checkout.ts` - типы для формы оформления заказа, доставки, офисов Econt

### 2. Библиотека Econt API
- `lib/econt.ts` - функции для работы с Econt API:
  - `getEcontCities()` - получение всех городов Болгарии

  - `getEcontAllPoints(cityId)` - получение всех точек выдачи

### 3. API Endpoints
- `app/api/econt/cities/route.ts` - получение городов
- `app/api/econt/offices/route.ts` - получение офисов
- `app/api/checkout/route.ts` - обработка заказа (обновлено)

### 4. Компоненты
- `components/CheckoutModal.tsx` - модальное окно оформления заказа с:
  - Формой личных данных
  - Выбором способа оплаты
  - Выбором метода доставки
  - Динамической загрузкой офисов Econt
  - Расчетом итоговой суммы с доставкой

### 5. Обновленные страницы
- `app/[locale]/checkout/page.tsx` - использует CheckoutModal
- `app/[locale]/checkout/success/page.tsx` - поддержка наложенного платежа

### 6. Telegram уведомления
- `app/api/checkout/route.ts` - отправка уведомления при наложенном платеже
- `app/api/webhooks/stripe/route.ts` - отправка уведомления при оплате картой
- Сообщения включают все данные доставки

## 🚀 Использование

### Процесс оформления заказа:

1. **Пользователь переходит на `/checkout`**
   - Видит список товаров в корзине
   - Нажимает кнопку "Продължи към поръчка"

2. **Открывается модальное окно CheckoutModal**
   - Заполняет личные данные (имя, фамилия, email, телефон)
   - Выбирает способ оплаты:
     - Кредитная/дебетовая карта
     - Наложен платеж
   - Выбирает метод доставки:
     - До офиса/автомата Econt (6 лв)
     - До адреса (7 лв)
   - Выбирает город
   - При доставке в офис - выбирает офис/автомат
   - При доставке на адрес - вводит адрес
   - Может добавить примечания к заказу

3. **Оплата картой**:
   - Перенаправление на Stripe Checkout
   - После оплаты - webhook отправляет уведомление в Telegram
   - Очистка корзины
   - Перенаправление на `/checkout/success`

4. **Наложенный платеж**:
   - Немедленная отправка уведомления в Telegram
   - Очистка корзины
   - Перенаправление на `/checkout/success?cash=true`

## 🐛 Возможные проблемы

### Econt API не возвращает данные:
- Проверьте переменные `ECONT_API_URL`, `ECONT_USERNAME`, `ECONT_PASSWORD`
- Проверьте логи в консоли браузера и в терминале

### Telegram не получает уведомления:
- Проверьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
- Убедитесь, что бот добавлен в чат
- Проверьте логи сервера

### Stripe webhook не работает:
- Убедитесь, что `stripe listen` запущен
- Проверьте `STRIPE_WEBHOOK_SECRET`
- Проверьте логи webhook в Stripe Dashboard

Отредактируйте `types/checkout.ts`:
```typescript
export const DELIVERY_PRICES = {

  econt_address: 7.0, // лв
```
